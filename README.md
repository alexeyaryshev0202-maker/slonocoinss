# 🏦 БАНК СЛОНОКОИН

**Полностью рабочий банк с виртуальной валютой SLC (Slonocoins)**

## 🚀 Возможности

✅ **Регистрация и авторизация** - создайте аккаунт и получите 1000 SLC на счёт  
✅ **Мгновенные переводы** - переводите SLC другим пользователям с комиссией 5%  
✅ **Кредитная система** - берите кредиты под 5% на срок до 30 дней  
✅ **Друзья и быстрые переводы** - добавляйте друзей по кодам  
✅ **Административная панель** - полный контроль над банком (если знаете код)  
✅ **Подробная история** - все операции записываются и сохраняются  
✅ **Экспорт данных** - сохраняйте свои транзакции в файл  

## 🎮 Быстрый старт

1. **Откройте `index.html`** в браузере
2. **Зарегистрируйтесь** или войдите
3. **Начинайте пользоваться банком!**

### Тестовые аккаунты:
- **Логин:** `admin` / **Пароль:** `admin123` (администратор)
- Или создайте свой аккаунт

## 🔐 Админ-доступ

**Секретный код:** `SLCADMIN2024`

Введите этот код в разделе "Админка" для получения полного контроля:
- Просмотр всех пользователей
- Изменение балансов
- Одобрение/отклонение кредитов
- Статистика банка

## 💰 Валюта

**SLC (Slonocoins)** - виртуальная валюта банка:
- Начальный баланс: 1000 SLC
- Минимальный перевод: 1 SLC
- Комиссия за перевод: 5%
- Максимальный кредит: 10,000 SLC

## 🛠 Технические особенности

- **100% frontend** - работает полностью в браузере
- **LocalStorage** - данные сохраняются локально
- **Адаптивный дизайн** - работает на всех устройствах
- **Без сервера** - никаких внешних зависимостей
